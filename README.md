_What this project is about?_

**High-Performance RAG Architecture** — Built a lightweight, low-latency Retrieval-Augmented Generation (RAG) pipeline using FastAPI and Python, with asynchronous endpoints for multi-page PDF ingestion and real-time semantic querying.

**Vector Search & LLM Inference** — Integrated SentenceTransformers for high-dimensional local embeddings, FAISS for fast similarity search, and Groq API for ultra-low-latency, context-aware LLM responses.
